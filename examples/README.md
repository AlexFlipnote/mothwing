# Examples
What mothwing does, part by part, each a small site of its own. Read them on [mothwing.dev](https://mothwing.dev/examples/), or build one from the repository's root:

```sh
node bin/mothwing.js dev --root examples/data
```

- [Data](data/): the data folder and placeholders
- [Loops](loops/): `<x-each>` and `<x-if>`
- [Pages](pages/): URLs, a page per item, and `.data.js`
- [Tags](tags/): the tags mothwing builds into HTML
- [Making it yours](making-it-yours/): your own tags, transforms and hooks
- [Going live](going-live/): the sitemap, robots.txt, CSP and the rest of what's turned on to publish
