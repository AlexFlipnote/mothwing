mothwing API GitHub

API

What mothwing and mothwing/html export, for scripts that build a site themselves and for typing mothwing.config.js.

ActiveLink Callback type
Decides what a link on a page is to it: "page" for the page itself, "section" for a section it's in, false for neither.
build Function
The production build, from an empty build folder.
clean Function
Function clean, from mothwing
Config Type
What a site's mothwing.config.js default exports.
defineConfig Function
Gives the config its types in your editor, it's returned as it is.
dev Function
Builds, serves and rebuilds what changes.
escapeHtml Function
Function escapeHtml, from mothwing
Hook Callback type
Run once the pages are written, dev is true on dev renders.
html Function
Function html, from mothwing
Html Class
HTML that's safe to put in as-is.
JsConfig Type
Each file is bundled to the same path in the build, js/index.js -> /js/index.js.
loadConfig Function
Function loadConfig, from mothwing
log Function
Function log, from mothwing
raw Function
Function raw, from mothwing
renderSite Function
Renders the pages into an existing build, as dev does after a change.
resolveConfig Function
Function resolveConfig, from mothwing
RobotsConfig Type
Type RobotsConfig, from mothwing
Route Type
A page to write.
SeoConfig Type
Type SeoConfig, from mothwing
Site Type
The config with its defaults filled in, its folders absolute, and each extra either false or its settings.
SitemapConfig Type
Type SitemapConfig, from mothwing
slug Function
Function slug, from mothwing/html
TagFunction Callback type
Returns the HTML a tag turns into.
Transform Callback type
Run on every page's HTML once its placeholders are filled, returns the HTML to write.
unescapeHtml Function
Function unescapeHtml, from mothwing
